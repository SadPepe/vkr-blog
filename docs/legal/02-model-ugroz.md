## 2. Категории обрабатываемых данных и субъекты

Категория персональных данных — **иные** (не специальные, не биометрические,
не общедоступные по умолчанию).

Обрабатываются: ФИО или отображаемое имя, логин, адрес электронной почты (если
указан), хеш пароля, изображения (аватар, обложка, иллюстрации), сведения «о себе»
и ссылки, пользовательский контент, IP-адрес, User-Agent, идентификатор сессии,
файлы cookie, сведения о просмотрах, сведения о согласиях.

Субъекты: зарегистрированные пользователи (авторы и читатели), незарегистрированные
посетители сайта. Общее число субъектов — **менее 100 000**.

## 3. Определение типа угроз и уровня защищённости

Тип актуальных угроз — **3-й**: угрозы, не связанные с наличием недекларированных
возможностей в системном и прикладном программном обеспечении. Основание: ИСПДн
построена на свободно распространяемом программном обеспечении с открытым исходным
кодом, обновляется по мере выхода исправлений, средства разработки и прикладные
компоненты получены из официальных источников.

Расчёт уровня защищённости по Постановлению Правительства РФ от 01.11.2012 № 1119:

| Признак | Значение |
|---|---|
| Категория ПДн | иные |

| Число субъектов | менее 100 000 |
| Доступ лиц, допущенных оператором | имеется (администрирование сайта и базы данных) |

**Установленный уровень защищённости — УЗ-3.**

## 4. Актуальные угрозы

| № | Угроза | Источник | Вероятность | Меры |
|---|---|---|---|---|
| 1 | Несанкционированный доступ через уязвимости веб-приложения (SQL-инъекции, обход авторизации) | внешний нарушитель | средняя | параметризованные запросы ORM, валидация входных данных на сервере, обновление зависимостей |
| 2 | Межсайтовый скриптинг (XSS) через пользовательский контент | внешний нарушитель | средняя | санитайзер HTML с белым списком тегов, экранирование вывода |
| 3 | Подделка межсайтовых запросов (CSRF) | внешний нарушитель | низкая | CSRF-токены, заголовок SameSite у сессионных cookie |
| 4 | Подбор паролей, автоматизированный перебор учётных записей | внешний нарушитель | средняя | ограничение частоты запросов (rate limiting), минимальная длина пароля, хеширование bcrypt |
| 5 | Компрометация учётной записи с административными правами | внешний или внутренний нарушитель | средняя | разграничение ролей (пользователь / модератор / администратор), отдельный вход в панель управления, ограничение доступа к панели по роли |
| 6 | Перехват трафика и сессионных данных | внешний нарушитель | низкая | HTTPS (TLS 1.2+), HSTS, флаг Secure у cookie, HttpOnly |
| 7 | Утечка данных через резервные копии | внешний или внутренний нарушитель | средняя | хранение копий в ограниченном доступе, срок хранения 30 дней, периодическая проверка восстановления |
| 8 | Утечка через журналы и отладочный вывод | внутренний нарушитель | низкая | отключён режим отладки в рабочей среде, ограничен доступ к журналам, очистка детальных записей о просмотрах (`views:prune`) |
| 9 | Заражение сервера вредоносным программным обеспечением | внешний нарушитель | средняя | антивирусная защита, минимальный набор служб, обновление образов |
| 10 | Утечка по вине лица, допущенного к обработке | внутренний нарушитель | низкая | перечень допущенных лиц, ознакомление под подпись, минимальные права доступа |
| 11 | Потеря или искажение данных при сбое оборудования | техногенный | средняя | резервное копирование, контроль восстановления |
| 12 | Несанкционированный физический доступ к серверу | внешний нарушитель | низкая | режим помещения, ограничение физического доступа, пароль на загрузку |

Угрозы, связанные с наличием недекларированных возможностей в системном и
прикладном ПО, а также угрозы со стороны специальных служб иностранных государств
как актуальные не рассматриваются.

## 5. Реализованные меры (приказ ФСТЭК России № 21)

| Группа мер | Реализация |
|---|---|
| Идентификация и аутентификация | вход по логину и паролю, пароли хранятся в виде хешей bcrypt |
| Управление доступом | роли пользователь / модератор / администратор, доступ в панель управления только по роли и при отсутствии блокировки |
| Ограничение среды | контейнерная изоляция служб, отсутствие лишних сетевых портов |
| Регистрация событий безопасности | журналы веб-сервера и приложения, журнал действий модерации |
| Антивирусная защита | антивирусная защита сервера |
| Контроль целостности | контроль версий кода (git), неизменяемые образы контейнеров |
| Защита каналов связи | HTTPS (TLS), HSTS, Secure/HttpOnly cookie |
| Резервное копирование | регулярные копии базы данных и файлов, хранение 30 дней |
| Управление обновлениями | регулярное обновление зависимостей и образов |
| Реагирование на инциденты | порядок действий оператора, уведомление Роскомнадзора при инциденте |
