# Журнал учёта обращений субъектов персональных данных

> Приложение 4 к приказу от {{ДАТА}} № {{НОМЕР}}. Ведётся непрерывно.

## Правила ведения

- Регистрируется каждое обращение: запрос на доступ к своим данным, требование об
  уточнении, блокировании или уничтожении, отзыв согласия, жалоба.
- Срок ответа — **10 рабочих дней** с даты получения. Он может быть продлён не
  более чем на **5 рабочих дней** с уведомлением заявителя (ст. 20 152-ФЗ).
- Если обращение поступило в электронной форме, ответ направляется на указанный
  заявителем адрес электронной почты.
- Запросы уполномоченных органов регистрируются в этом же журнале.
- Журнал хранится не менее 3 лет.

## Форма журнала

| № | Дата поступления | Субъект (ФИО или логин) | Контакт для ответа | Канал | Суть обращения | Срок ответа | Дата ответа | Результат |
|---|---|---|---|---|---|---|---|---|
| 1 | | | | сайт / email / почта | | | | |
| 2 | | | | | | | | |

## Пометки по типовым обращениям

| Обращение | Что сделать | Срок |
|---|---|---|
| Запрос сведений об обработке | предоставить перечень данных, цели, способы, сроки, сведения о лицах с доступом | 10 рабочих дней |
| Требование об уточнении | исправить данные в профиле или вручную в базе, зафиксировать | 7 рабочих дней с даты получения сведений о неточности |
| Требование об уничтожении | удалить данные и файлы (аватары, обложки, картинки статей), подтвердить заявителю | 30 дней |
| Отзыв согласия | прекратить обработку, уничтожить данные, кроме тех, что обязательно хранить по закону | 30 дней |
| Удаление аккаунта | удалить запись и связанные файлы, подтвердить | по запросу |

Результат в журнале описывается кратко: «ответ направлен», «данные уточнены»,
«данные уничтожены, акт от {{ДАТА}}».
