# Документы по персональным данным

Комплект для оператора — физического лица, сайт «Челны подземка»
(`chelnipodzemka.ru`). Соответствует сведениям, указанным в уведомлении РКН
(заявление № 100495167 от 11.11.2026).

Это **шаблоны**, а не юридическое заключение. Перед использованием их должен
просмотреть юрист (например, юрист вуза).

## Порядок работы

1. Скопируйте файлы в отдельную папку вне репозитория (`Документы/ПДн/`).
2. Замените все `{{...}}` на свои данные: ФИО, адрес, email, домен.
3. Распечатайте, подпишите, поставьте дату — документы нужны на бумаге.
4. Храните вместе с копией уведомления РКН.

В репозиторий **не попадают** ФИО, адрес и ключ доступа к уведомлению. В шаблонах
стоят подстановки, поэтому файлы можно держать в git и использовать как основу
для новой редакции.

## Сверка с заявлением в РКН

В уведомлении указано: иные категории ПДн, угрозы 3-го типа, менее 100 000
субъектов, доступ имеют лица, допущенные оператором, уровень защищённости УЗ-3.
Документы ниже обосновывают именно эти сведения. Если меняется инфраструктура
(появляется хостинг-провайдер, аналитика, мобильное приложение), сначала
переписываются модель угроз и оценка вреда, потом уведомление РКН — в течение
15 дней.
