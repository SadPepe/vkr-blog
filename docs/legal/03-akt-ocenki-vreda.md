# Акт оценки вреда, который может быть причинён субъектам персональных данных

> Приложение 2 к приказу от {{ДАТА}} № {{НОМЕР}}. Оценка проводится в соответствии
> со ст. 18.1 Федерального закона от 27.07.2006 № 152-ФЗ. Шаблон: заменить `{{...}}`.

**Оператор:** {{ФИО_ПОЛНОСТЬЮ}}
**Дата проведения оценки:** {{ДАТА}}
**ИСПДн:** сайт-блог «Челны подземка» (`https://{{ДОМЕН}}`)

## 1. Методика

Вред оценивается по двум критериям: **вероятность** причинения и **тяжесть**
последствий для субъекта. Учитываются характер обрабатываемых данных, объём,
срок хранения, круг лиц с доступом и реализованные меры защиты.

Шкала: низкая / средняя / высокая.

## 2. Оценка по категориям субъектов

### 2.1. Зарегистрированные пользователи (авторы и читатели)

| Показатель | Значение |
|---|---|
| Обрабатываемые данные | отображаемое имя (может содержать ФИО), логин, email (если указан), хеш пароля, изображения, «о себе», ссылки, контент, IP-адрес, User-Agent, cookie, сведения о просмотрах |
| Возможные последствия | моральный вред при раскрытии имени, изображения или email; попытки мошенничества при утечке email; затруднение доступа к аккаунту; репутационные последствия |
| Вероятность | средняя |
| Тяжесть | средняя |
| Оценка вреда | **умеренный** |

### 2.2. Незарегистрированные посетители

| Показатель | Значение |
|---|---|
| Обрабатываемые данные | IP-адрес, User-Agent, cookie, сведения о просмотрах |
| Возможные последствия | установление факта посещения сайта, объединение сведений о посещениях |
| Вероятность | низкая |
| Тяжесть | низкая |
| Оценка вреда | **незначительный** |

### 2.3. Лица, обратившиеся с запросом или жалобой

| Показатель | Значение |
|---|---|
| Обрабатываемые данные | имя или логин, email, содержание обращения |
| Возможные последствия | раскрытие содержания обращения и факта его подачи |
| Вероятность | низкая |
| Тяжесть | средняя |
| Оценка вреда | **умеренный** |

## 3. Факторы, снижающие вред

- email указывается по желанию и не отображается в публичном профиле;
- логин скрыт из публичного профиля;
- пароли хранятся только в виде необратимых хешей;
- специальные категории и биометрические данные не обрабатываются;
- публикация профиля возможна только при отдельном согласии на распространение;
- доступ к базе данных и административной панели ограничен и разграничен по ролям;
- детальные записи о просмотрах хранятся ограниченное время и удаляются по расписанию;
- утечка данных, приводящая к тяжёлым последствиям, требует одновременного
  преодоления нескольких рубежей защиты, что снижает вероятность.

## 4. Вывод

Вред, который может быть причинён субъектам персональных данных, оценивается как
**незначительный для незарегистрированных посетителей и умеренный для
зарегистрированных пользователей и лиц, обратившихся с обращением**.

Реализованные меры защиты соответствуют уровню защищённости УЗ-3 и достаточны для
снижения выявленных рисков. Дополнительные меры не требуются.

Оценка подлежит пересмотру при изменении состава обрабатываемых данных, появлении
новых целей обработки, подключении внешних сервисов (аналитика, облачное хранение,
почтовый провайдер) или изменении инфраструктуры, а также не реже одного раза в три
года.
